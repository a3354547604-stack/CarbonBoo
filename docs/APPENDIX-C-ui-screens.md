## 2. 导航结构

```
EntryAbility
└─ NavigationStack（root）
   └─ MainPage = Tabs（barPosition: End，5 个 Tab）
      ├─ Tab 0  首页      HOME
      ├─ Tab 1  看板      DASHBOARD
      ├─ Tab 2  记录      RECORD
      ├─ Tab 3  科普      SCIENCE
      └─ Tab 4  我的      MINE

导航栈（NavPathStack，供二级页 push）：
HOME ─┬─ GOAL ── BADGE
      ├─ RECORD_EDIT ── RECORD_DETAIL
      ├─ SHOP ── APPEARANCE
      └─ SCIENCE_DETAIL
MINE ─┬─ APPEARANCE / POINT_LOG / GOAL / BADGE / SHOP
      ├─ INCLUDE ── (RedeemConfirmDialog)
      ├─ SYNC
      ├─ SETTINGS ─┬─ ABOUT
      │            └─ (LoginDialog)
      └─ (ShareSheet)
```

**规则**
1. Tab 页**不进入导航栈**；切换 Tab 保留各自状态。
2. 二级页统一用 `NavPathStack.pushPath({ name, param })`；返回用 `pop()`。
3. Tab 2「记录」的悬浮按钮 → `RECORD_EDIT`；点击列表项 → `RECORD_DETAIL`。
4. 任何页面都能从 `SHOP` 拿到「碳小铺」；**碳普惠另开一页**（模拟演示提示条常驻）。

### 3.4 数字格式（全应用统一，禁止各页自定）

| 量 | 格式 | 示例 |
|---|---|---|
| 减排量 `kgCO₂e` | **固定 4 位小数**，千位不加分隔符 | `12.4800`、`0.9600` |
| 积分 | 整数 + **千分位逗号** | `4,820`、`+200` |
| 碳币 | 整数，无小数 | `48` |
| 因子值 | 固定 4 位小数 | `0.1920` |
| 时间 | `YYYY-MM-DD HH:mm`（列表）；`HH:mm`（同日） | `2026-11-06 14:40` |

**唯一实现**：`Formatter.number(value, kind)`（见 PLAN §7.12）；页面禁止自行 `toFixed()`。

> **上表的数字是"格式示例"，不是"演示数据规格"**：示意图（§9 我的页、§18.2 家庭合并等）沿用 `12.4800` /
> `4,820` / `48` 这组样例只为演示位数与千分位；**演示数据规格的唯一来源是 [附录 D §9/§9.1](./APPENDIX-D-acceptance.md)**
> （90 天累计减排 **≈61.7400 kgCO₂e**、积分余额 **4,820–4,919**、自动解锁 6 枚）。两处不是同一件事，别互相抄。

- 云端备份：登录成功后显示 `已登录：xxx` + `[ 立即上传 ]`（快照上传）/ `[ 立即恢复 ]`（**覆盖式恢复**，恢复前自动生成本地快照）+ `[ 退出登录 ]` / `[ 注销账号 ]`（`LoginDialog` 内，二次确认 + 输入密码；云端软删除保留 30 天，**本机数据一条不删**）。
- **未登录、无网络时本页除「云端备份」外全部功能可用**（铁律 1）。

## 23. 半模态与弹窗

### 23.1 `AiRecognizeSheet`（端侧识图，创新项 Ⅱ）

```
┌──── 识图结果 ────────────────────────┐
│ [图片缩略图]                          │
│ 识别到：🚲 骑行                        │
│ 其他候选：                            │
│   🚶 步行            🚌 公交          │
│                                       │
│ 请确认行为类型：                       │
│ [🚲 骑行 ✓] [🚶 步行] [🚌 公交]        │
│ 活动量  [ 5 ] km                      │
│                        [ 使用此结果 ] │
└──────────────────────────────────────┘
```

**规则（重要）**
1. 接口签名：`AiAssistService.recognize(uri: string): Promise<AiRecognizeResult>`。
2. **超时 3 秒**；`recognized = false` 或超时 → 自动关闭本半模态，退回**「图标网格快速录入」**并提示「识图不可用，请手动选择」。
3. **图片不落盘、不上传**；只读一次像素做本地推断。
4. **只给候选，必须用户确认后才预填表单**，绝不自动保存。
5. 本期实现为**「接口层 + 假数据兜底」**：`engine = 'mock'` 时返回基于文件名/简单启发式的结果；拿到真模型后只替换底层实现，**上层不动**。
6. ⚠ **模拟态标注（必须实现）**：`engine = 'mock'` 时，**识图半模态内必须常驻与 `SimulationBanner` 同级的「模拟识别」提示条**（不得只挂在碳普惠页）。**界面不得展示置信度数字或准确率**，避免把桩实现表现为已训练模型。

### 23.2 `ShareSheet`（减排成果社交分享，创新项 Ⅳ）

```
┌──── 生成分享卡片 ────────────────────┐
│ 尺寸  [ 1080×1440 竖版 ] [ 1080×1080 方版 ]
│ ┌────────────────────────────┐        │
│ │   碳小布 · carbonboo        │        │
│ │   我的累计减排              │        │
│ │      12.4800 kgCO₂e         │        │
│ │   ≈ 0.68 棵树一年吸收量      │        │
│ │   ≈ 少开 65 km 车            │        │
│ │   已解锁徽章  ◎◎◎           │        │
│ │              OpenHarmony    │        │
│ └────────────────────────────┘        │
│ [ 保存到相册 ]      [ 系统分享 ]       │
└──────────────────────────────────────┘
```

**规则**
1. `Canvas` 本地绘制，**两种尺寸**；内容含累计减排、等效换算、已解锁徽章、碳小布与 OpenHarmony 标识。
2. **默认不含姓名 / 学校 / 队名 / 指导教师**；昵称选填，留空显示「碳小布用户」。
3. 保存到相册用 **`photoAccessHelper`** 的保存控件（`saveButton` / `createAsset`）——`@ohos.file.picker` 只用于**选择**图片，不用于保存；相册写权限按需声明 `ohos.permission.WRITE_IMAGEVIDEO`。分享走**系统分享面板**，**不接任何第三方社交 SDK**。
4. 生成后写 `share_record`（本机专属，不参与同步）。

### 23.3 `LoginDialog`（登录 / 注册 / 注销）

双 Tab：**登录**（用户名 + 密码）/ **注册**（用户名 4–20 位字母数字下划线 + 密码 6–32 位 + 确认密码）；错误码沿用附录 B §5.2 表；**不接短信/邮件验证码**，不做华为账号（Account Kit）。

- **登录成功后**：token 只经 `AuthProvider` / `AuthDao` 落到 `preferences`（页面/ViewModel 不得直接读写 token）；随后按 ADR-0001 决策 ① 弹「本机已有 N 条记录，将并入该账号并开始同步」并执行 `AccountMigrator` + 首次全量上传。
- **已登录态**：同一半模态展示 `已登录：xxx` + `[ 退出登录 ]`（清 token，本机数据不动）+ `[ 注销账号 ]`（二次确认 + 输入密码；云端软删除保留 30 天，期间可恢复）。

### 23.4 `RedeemConfirmDialog`

显示：商品/权益名、价格、当前余额、扣后余额；确认按钮为主色。用于碳小铺购买与碳普惠兑换。

### 23.5 `UnlockCelebrationDialog`

圆形徽章/目标图标 + 名称 + 「已获得 +n 分」（徽章则显示「荣誉徽章，不发放积分」）+ 「知道了」。多个同时解锁时**排队弹出，最多连续 3 个**，其余折叠为一条汇总提示。

### 23.6 `DevOptionsSheet`（开发者选项，非交付功能）

**触发**：设置 → 关于与合规 → **连续点击版本号 7 次**。入口对普通用户不可见，**不影响任何验收路径的默认行为**。

```
┌──── 开发者选项 ──────────────────────┐
│ 保存强制抛错                  [ 关 ]  │
│ 数据库体积                    1.4 MB  │
│ 记录数 / 积分数                260 / 4,820 │
│ [ 重建 point_daily_stat ]             │
│ [ 播种演示数据 ]   [ 清除演示数据 ]    │
└──────────────────────────────────────┘
```

**规则**
1. 「保存强制抛错」→ 保存事务内主动抛异常，用于验收 **C4/C5**（要求两端表都不写入）；默认关闭，重启后自动复位为关。
2. 「数据库体积」显示 `relationalStore` 实际占用（验收 **P10**：260 条 < 2 MB）。
3. 「重建 `point_daily_stat`」调 `PointService.rebuildDailyStat(userId)`（验收 **D3-5**），完成后 Toast 报告重建行数。
4. 「播种演示数据」= 写入 `user_id = 'demo-user'`、`app_config['demo_mode'] = 1`（规格见附录 D §9）；「清除演示数据」按该 id 清除并复位开关。
5. 本半模态**不得**提供任何绕过业务规则的开关（不能改余额、不能改因子、不能跳过封顶）。
