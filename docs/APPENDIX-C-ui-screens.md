## 2. 导航结构

```
EntryAbility
└─ NavigationStack（root）
   └─ MainPage = Tabs（barPosition: End，5 个 Tab）
      ├─ Tab 0  首页      HOME
      ├─ Tab 1  看板      DASHBOARD
      ├─ Tab 2  记录      RECORD
      ├─ Tab 3  科普      SCIENCE
      └─ Tab 4  我的      MINE

导航栈（NavPathStack，供二级页 push）：
HOME ─┬─ GOAL ── BADGE
      ├─ RECORD_EDIT ── RECORD_DETAIL
      ├─ SHOP ── APPEARANCE
      └─ SCIENCE_DETAIL
MINE ─┬─ APPEARANCE / POINT_LOG / GOAL / BADGE / SHOP
      ├─ INCLUDE ── (RedeemConfirmDialog)
      ├─ SYNC
      ├─ SETTINGS ─┬─ ABOUT
      │            └─ (LoginDialog)
      └─ (ShareSheet)
```

**规则**
1. Tab 页**不进入导航栈**；切换 Tab 保留各自状态。
2. 二级页统一用 `NavPathStack.pushPath({ name, param })`；返回用 `pop()`。
3. Tab 2「记录」的悬浮按钮 → `RECORD_EDIT`；点击列表项 → `RECORD_DETAIL`。
4. 任何页面都能从 `SHOP` 拿到「碳小铺」；**碳普惠另开一页**（模拟演示提示条常驻）。

## 10. 页面 6 · 录入 RECORD_EDIT

```
← 记一笔
┌──── 📷 识图录入（端侧 AI，创新项 Ⅱ）────┐
│  选一张照片，自动推断低碳行为            │
│                            [选择图片]   │
└──────────────────────────────────────┘
  或 从下面选一个
┌──── 图标网格 ────────────────────────┐
│ 🚶步行  🚲骑行  🚌公交  🚇地铁         │
│ 🚗拼车  💡节电  💧节水  ♻️回收         │
│ 🍽️光盘                                │
└──────────────────────────────────────┘
────────────────────────────────────────────
已选：🚲 骑行
活动量                              [ 5 ] km
发生时间                      2026-11-06 14:20
备注（选填）                    [____________]
────────────────────────────────────────────
┌──── 减排预览 ────────────────────────┐
│  减排量      0.9600 kgCO₂e            │
│  因子        0.1920 kg/km             │
│  本次应得    96 分                     │
│  今日已得    104 / 200 分              │
│  实入        96 分                     │
└──────────────────────────────────────┘
                          [ 保存 ]
```

**规则（关键）**
1. **预览即时计算**：调用 `CarbonService.preview(input)`，返回 `CalculatePreview`；每次改动活动量/时间都重算，**节流 200ms**。
2. 预览必须展示 **应得 C / 今日已得 D / 实入 A** 三者；当 `A < C` 时在预览卡片顶部加黄条：**「今日记录积分已达上限，本笔实入 96 分（应得 96 分）」**——若完全封顶则显示「今日记录积分已达每日上限 200，本笔不发放记录积分」，并把「实入」显示为 `0 分`。
3. **目标奖励不计入 200 封顶**，在预览卡片下方单列一行「目标奖励不受上限影响」。
4. 数值超上限（出行 200 km / 节电 200 kWh / 节水 2000 L / 燃气 100 / 回收 500 kg / 光盘 20）→ 允许保存但标 `is_abnormal = 1`，并弹提示「数值超出常见范围，已记录并标记为异常」。
5. 活动量输入限制：数字键盘、最多 2 位小数、必须 > 0；否则「保存」置灰。
6. 保存成功 → 按 `SaveRecordResult.newGoals` / `newBadges` **排队**弹出 `UnlockCelebrationDialog`；返回上一页。
7. 编辑模式（带 `recordId`）：标题改「编辑记录」，预填原值；发生时间不可改到未来；保存时按差额生成 `reverse` 流水，`source_id = <记录ID>#<revision>`（见 PLAN §9.5）。
8. 发生时间可选范围：**今天 ~ 30 天前（含）**；不可选未来，也不可选更早（超窗日期在日期选择器里直接禁用）。
