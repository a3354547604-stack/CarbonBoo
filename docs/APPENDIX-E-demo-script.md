### 0:40–2:00｜产品是什么：五加四，九项全覆盖（⟶ P2 产品定位 / P3 功能全景）

「碳小布是一款基于开源鸿蒙、用 ArkTS 与 ArkUI 开发的个人碳账本应用，面向赛题的**单机版**要求设计：**不联网、不登录，全部功能可用**。

### 3:30–5:20｜技术架构：为什么这样设计（⟶ P5 架构图 / P6 数据层）

「接下来讲技术。整个应用分五层：**表现层**是 18 个 ArkUI 页面，五个底部页签加十三个二级页；**视图模型层**负责聚合与格式化；**服务层**是业务的唯一入口——减排量的计算只有 `CarbonService` 一个入口，任何页面都不许自己乘因子；**数据访问层**通过十二个 Dao 收口；**持久层**用 `relationalStore`，也就是鸿蒙原生的 SQLite，十九张表，所有多表写入走事务。

四条设计铁律：
**第一，本地优先。** 本机数据库是唯一真相源，分布式协同只是"搬运"，不参与业务。
**第二，单一计算入口。** 因子乘算只在一个地方发生。
**第三，因子快照。** 每条记录保存时把当时的因子值一起存下来，因子库以后升级，历史数据永不改写——这一点在碳核算里非常重要。
**第四，积分单向可追溯。** 积分只增可溯，每一分都能追到它来自哪条记录或哪个目标。」

### 5:20–7:20｜创新点：多设备协同（⟶ P7 协同架构 / P8 协同面板实拍）

「赛题把"超级终端多设备数据同步"列为创新加分项。我们的做法是：**把它做成可开关的一层，而不是地基。**

【两台设备并排展示】
这是两台鸿蒙设备，已经通过**鸿蒙分布式数据服务**完成配对。手机刚记的一笔地铁出行，在平板上立刻出现。
协同的关键设计有四点：
一是**增量**——只传上次协同之后被改动的记录，不是全量覆盖；
二是**幂等**——每条记录用 UUID 做全局唯一主键，重复合并不会产生重复数据；
三是**冲突解决用 LWW（最后写入优先）**，两台设备改了同一条记录时保留修改时间更新的一条，并把冲突次数暴露给用户；比较前还会做时钟偏移校正，避免设备时钟不准导致误判；
四是**删除也能传播**——删除是软删除加时间戳，所以设备间不会"复活"已删数据。
面板会显示设备标识、最后同步时间、三段进度、待同步条数、冲突记录数，**协同过程对用户是可见、可解释的**。切到家庭视图，两个人的减排和积分还能合并统计。」

### 7:20–8:20｜数据可信度与合规（⟶ P9 因子来源 / P10 合规对照）

「碳数据的说服力取决于因子来源。我们的因子库做到**每个值都有出处**：
用电因子采用生态环境部《2024 年全国电力碳足迹因子》，全国平均 **0.5703 千克二氧化碳当量每度电**；回收类取自《建筑碳排放计算标准》GB/T 51366；出行类统一按"**相对燃油车的净减排**"口径计算——也就是说，骑行五公里被记为少开五公里车，这一点在文档里写死了公式。部分因子标注为"参考值"，界面上带角标、文档里列入复核清单——**我们不假装所有数字都权威，但每个数字都能追溯。**

合规方面：开发环境为 DevEco Studio、基于 OpenHarmony、目标 API 12 及以上；纯北向，不涉及任何南向硬件采购；碳普惠接口明确标注"模拟演示"，不做真实对接、不可提现。」

### 8:20–9:30｜完成度与验收（⟶ P11 功能矩阵 / P12 验收数据）

「完成度方面：赛题二**九项要求全部有落地入口**，展开为功能矩阵逐项打勾；验收清单有一百二十余条可勾选项，其中碳计算有 **18 组手算样例**逐项比对，误差要求为零，并单列了封顶与边界的算法样例；性能目标是冷启动两秒内、看板一年数据三百毫秒内。

## §6 话术禁忌（路演时不要说）

1. **不要说"我们用了华为云 / AGC / IoT 平台 / 云账号体系"** —— v4.0 已改为鸿蒙分布式数据服务，说了即为不实陈述。
2. **不要宣称因子值全部权威** —— 出行与回收类为参考值，必须按"参考值"口径表述。
3. **不要说"碳普惠已经真实对接"** —— 必须表述为"**模拟实现**，页面已标注模拟演示，不做真实对接、不可提现"。
4. **不要提"多设备同步是必须的"** —— 官方明确定位为加分项，表述应为"可选增强层，单机态全部功能可用"。
5. **不要说"我们的 AI 能识别一切低碳行为"** —— 表述为"候选类型推荐 + 用户确认 + 不可用时的图标网格降级"。
   **也不得说"模型已训练""识别准确率 xx%"或展示任何置信度/准确率数字** —— 本期 `engine = 'mock'`，返回的是基于文件名/启发式的假数据（见附录 C §23.1 第 5 条）。
6. **不要说"识别的图片会上传云端"或暗示图片离开设备** —— 必须说明图片不落盘、不上传。
7. **不要出现校名、队名、指导教师姓名**（材料与口播均不出现）。
8. **不要说"植树证书"** —— 该设计已废弃，v4.0 对应的是碳普惠模拟权益。
9. **不要使用"全国第一 / 唯一 / O(1) 最优"等无法验证的绝对化表述。**
