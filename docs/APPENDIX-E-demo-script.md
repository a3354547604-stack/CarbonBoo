## §2 5 分钟演示视频脚本（分镜表）

> 每行 = 一个分镜：时间段 / 屏幕操作 / 旁白 / 画面要点。

### 分镜 1 · 开场与首页（0:00–0:20，20s）

| 项 | 内容 |
|---|---|
| 操作 | 冷启动应用（从桌面点击图标）→ 停留在首页 |
| 旁白 | 「大家好，这是碳小布——一款运行在开源鸿蒙上的个人碳账本。它把每天的低碳行为，换算成看得见的减排量和碳积分。首页一眼就能看到：今天减排了多少、拿了多少积分、已经连续记录多少天。」 |
| 画面要点 | 首页从上往下缓动滚动一次：累计减排卡（含等效换算）、碳积分小卡与今日记录卡、今日目标、近 7 天迷你柱、今日建议、悬浮「＋ 记一笔」 |

| 旁白 | 「记录只要十秒。选行为类型——比如骑自行车——填入里程，应用内置的碳排放因子库立刻算出减排量：骑行 5 公里，相当于少开 5 公里燃油车，减少 0.96 千克二氧化碳，同时获得 96 积分。保存后，首页的数字立刻更新。」 |

## §6 话术禁忌（路演时不要说）

1. **不要说"我们用华为账号 / AGC / IoT 平台 / 第三方云托管登录"** —— 账号是**自建体系**（用户名 + 密码 + bcrypt + 双 JWT），不接华为账号（Account Kit）；也不要说"数据绝不上云"——正确表述是"默认本地，仅在你登录后上传行为数据，可随时退出登录或注销"。
2. **不要宣称因子值全部权威** —— 出行与 10 个对照类为推算值、回收类 8 个与光盘类 2 个为"参考值"，必须按"参考值 / provisional"口径表述，不得说"权威""国标认证"。
3. **不要说"碳普惠已经真实对接"** —— 必须表述为"**模拟实现**，页面已标注模拟演示，不做真实对接、不可提现"。
4. **不要提"多设备同步是官方必做项"** —— 它在赛题里是**创新加分项**；但按 ADR-0001，本项目**自己把它做成了必做件**，表述应为"未登录即单机；登录后启用多设备同步与云端备份"。
5. **不要说"我们的 AI 能识别一切低碳行为"** —— 表述为"候选类型推荐 + 用户确认 + 不可用时的图标网格降级"。
   **也不得说"模型已训练""识别准确率 xx%"或展示任何置信度/准确率数字** —— 本期 `engine = 'mock'`，返回的是基于文件名/启发式的假数据（见附录 C §23.1 第 5 条）。
6. **不要说"识别的图片会上传云端"或暗示图片离开设备** —— 必须说明图片不落盘、不上传。
7. **不要出现校名、队名、指导教师姓名**（材料与口播均不出现）。
8. **不要说"植树证书"** —— 该设计已废弃，v4.0 对应的是碳普惠模拟权益。
9. **不要使用"全国第一 / 唯一 / O(1) 最优"等无法验证的绝对化表述。**
