# 碳小布 CarbonBoo

> 运行在 **OpenHarmony** 上的**个人碳账本**应用：把日常低碳行为（出行、节水节电、旧物回收、光盘行动）量化成**减排量**与**碳积分**，用**目标 · 徽章 · 碳小铺**三层激励帮用户把低碳习惯坚持下去。

- **赛题**：第三届河南省高等学校信息技术应用创新大赛 · **赛题二「碳足迹·全民绿色生活碳积分与减排指南」**（纯北向应用开发类）
- **产品名**：中文「碳小布」／英文「CarbonBoo」；包名 `com.carbonboo.app`
- **当前阶段**：计划已定稿（文档 v4.1），**尚未开始编码**；`app/`、`server/` 将在编码阶段创建
- **文档定位**：内部规格文档，**只约束代码与最终效果**，不对外发布、不作为比赛提交物

## 四条铁律

1. **本地优先** —— 本机 `relationalStore` 是唯一真相源；云端同步与近场协同只做「搬运」，不参与业务计算。**例外（可依赖网络）**：登录/注册、多设备同步、商品取价、云端备份。
2. **单一计算入口** —— 减排量计算**只能**在 `CarbonService.calculate()` 里发生，任何页面禁止自己乘因子。
3. **因子快照** —— 每条碳记录保存时把当时的因子值、版本、来源一并存下；因子库升级不改写历史。
4. **积分单向可追溯** —— 余额 = 收入 − 支出；积分流水只增不删，任何一条都可回溯到来源。

> 任何一行代码与铁律冲突，**改代码，不改铁律**。详见 [docs/PLAN.md §3](./docs/PLAN.md)。
